# Kerolos Fawzy Portfolio

Resume-based full-stack and mobile developer portfolio built with Next.js and TypeScript. Features DocMoonLight, Zacks, and IDEX, accessible contact and social links, light/dark themes, and a downloadable resume.

Run `npm install`, then `npm run dev` for local development. Run `npm run build` for a checked production build and static export in `out/`.

The Sites project identity and static output directory are stored in `.openai/hosting.json`. Publish through the Sites workflow using the exported `out/` directory. No environment variables are required.
